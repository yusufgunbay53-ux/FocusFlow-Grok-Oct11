# FocusFlow - AI Destekli Görev ve Odaklanma Asistanı

Modern, karanlık mod odaklı, neon mavi temalı bir görev yönetimi ve odaklanma uygulaması.

## Özellikler

- **Kanban Board**: Sürükle-bırak ile Yapılacaklar / Yapılıyor / Tamamlandı
- **Görev Yönetimi**: Öncelik etiketleri (Düşük, Orta, Yüksek), düzenleme, silme
- **Pomodoro Sayacı**: 25/5 dakika, tarayıcı bildirimi + sesli uyarı
- **Ambient Sesler**: Lo-Fi, Yağmur ve Kahve dükkanı sesleri
- **AI Performans Koçu**: Günlük ilerlemeye göre akıllı geri bildirimler (mock)
- **localStorage**: Sayfa yenilense bile veriler kalır
- **PWA Hazır**: Mobil uyumlu, dark glassmorphism tasarım
- **Teknoloji**: React + Vite + TypeScript + Tailwind CSS + Lucide React + @dnd-kit

## Kurulum

```bash
npm install
npm run dev
```

## Gelecek

Veri yapıları temiz tutulduğu için Supabase veya Firebase'e kolayca bağlanabilir.
